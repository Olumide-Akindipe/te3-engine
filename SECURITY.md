# Security Policy

## Reporting a vulnerability

Please report security issues privately through the **Report a vulnerability** button on the
**Security** tab of this repository. Do not open a public issue.

I aim to acknowledge reports within 7 days.

## Scope

This policy covers the TE3 Engine code in this repository and the public app at
https://te3-engine.streamlit.app. TE3 stores no user data; see the Privacy section of the README.

## Supported versions

Security fixes are made to the latest release only.
