# Contributing to TE3 Engine

Thank you for your interest in TE3 Engine.

TE3 Engine is developed and maintained by a single author. Code
contributions (pull requests) are not accepted at this time.

You are welcome to:

- Report a bug or a data error by opening an issue.
- Suggest a feature or a data source by opening an issue.
- Send feedback through the form linked in the app.

Reported issues are fixed by the maintainer. Security issues should be
reported as described in SECURITY.md.
